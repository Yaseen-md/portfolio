# Mohammed Yaseen — Portfolio

Personal engineering portfolio focused on **Intelligent Systems & Quality Engineering** (`Applied AI · Quality Engineering · Systems Reliability`).

## Stack

- **Framework:** React 18 + Vite 7
- **Styling:** Tailwind CSS 3 + custom CSS design tokens (`src/index.css`)
- **Routing:** Lightweight History API router (`src/lib/router.js`) supporting `/` and `/projects/:slug` case-study pages
- **Motion:** Centralized CSS + `IntersectionObserver` motion primitives (`src/components/motion/`) with `prefers-reduced-motion` support
- **Icons:** `lucide-react`

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
